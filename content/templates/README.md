# 検証済み作品データ

既存の検証済みカタログを保守するための資料です。現行の[仕様v3.1](../../docs/specifications/co-make-v3-1.md)ではAIが材料から3案を生成し、このカタログの登録を待ちません。#12はAI案の実物検証を担当します。
shared/src/workshop.tsのTemplateSchema（schemaVersion=2）を正本にします。

日英の材料名/単位と数量、工具、寸法や状態の確認質問、日英の手順/注意と実写写真を揃えます。
工程は本人が実行する順に並べ、人数・担当パーツ・割当を含めません。
実物試作と写真/翻訳/利用許諾を確認するまで公開しません。AI生成写真とテストfixtureは公開データに含めないでください。

ここに置いたJSONは互換・確認条件用としてアプリに同梱されます（src/data/templates.ts）。新しい3案の作品情報は候補文書のtemplatesから取得します。スキーマに合わないファイルは表示しません。
現在は検証済みデータ未登録です。追加3作品は初期版の対象外です。

## 公開と判定の契約

JSONはこのフォルダ直下の*.json、工程の実写はpublic/steps配下に置きます。npm run build:functionsが全JSONをVerifiedTemplateCatalogSchemaで検証し、写真の欠落を拒否してサーバーへ埋め込みます。登録時はWeb/Functionsを同じカタログでビルドしてください。

- カタログは最大20作品で、作品IDは重複させません。
- 同じ作品内で材料名の日英表記が別の材料要件と重なると二重計上になるため拒否します。材料名は80文字、単位は20文字以内です。
- 確認条件IDを作品間で共有する場合は、日英の質問文も同じにします。異なる条件には別IDを付けます。
- 材料名と単位は正規化後の日英表記に完全一致するものだけを照合します。寸法/厚さ/状態はchecksで尋ね、工具は具体的な種類を指定します。「のり」を「スティックのり」の代用にはしません。
- 作品や質問の変更はカタログ版を変え、保存済みの回答での確定を拒否します。再編集・再確認が必要です。

正確な照合規則とFEへの引き渡しは[材料API v2](../../docs/api/materials-v2.md)を参照してください。
