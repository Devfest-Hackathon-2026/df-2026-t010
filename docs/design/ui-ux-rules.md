# UI・UX開発ルール

2026-11-07更新: 現行の画面構成と配色は[Rekt v3.1](../specifications/co-make-v3-1.md)とユーザーの参考画像を優先します。ホームと作品の比較は角丸の選択肢、完成画面は中央配置を使います。AI作品に実写がない場合は、写真を装わずPhosphorのイメージアイコンを表示します。

2026-11-05 ユーザー指定。Rektの全画面・共通部品・今後のPRに適用する。UX/実装は @okaka-1205、見た目と操作性の提案・検証は @motimoti-03。担当外の変更にもこのルールを適用する。

## 文言を増やさない（2026-11-07 ユーザー指定）

不要な見出し・説明文・注意書きは全画面から削除し、今後も追加しない。日本語・英語の両方に適用する。

- ホームの長い紹介文、キャッチコピーの補足、選択肢の説明、操作から分かる案内、常時表示の注意書き、重複する見出し・小見出しを置かない。
- 説明のための説明、空白を埋める文章、予防的な免責文を追加しない。必要か迷う文言は追加しない。
- 画面名、入力ラベル、操作、作品・工程の内容、発生中のエラー・処理状態だけを必要な場所に短く表示する。
- 開発用やサンプルは短い状態ラベルで区別する。実装、接続設定、保存先の詳細は開発文書へ記載する。
- 削除した文章をフッター、ツールチップ、折りたたみなど別の場所へ移して再追加しない。
- 工程ごとの定型の注意書き・警告枠も表示しない。AI・体験版・既存作品の`step.safety`を画面へ出さず、削除した注意文を工程本文へ移して戻さない。実際の通信・入力エラーは引き続き表示する。

## 必須ルール

| 項目 | 実装ルール |
| --- | --- |
| スマホ優先 | 320〜430 CSS pxを先に設計する。横スクロールを作らず、縦スクロールで完結する。デスクトップは余白を広げて対応する |
| 見出し | ページの目的を示すh1を1つ置き、区切りが必要な箇所だけh2を使う。ラベル・補足・各行を見出しにしない |
| 写真 | アプリ内でAI生成写真を使用しない。工程・完成・材料は実際の写真とし、出典・撮影者/利用許諾を記録する。未撮影なら写真を捏造せず、説明文を埋め草にしない |
| アイコン | [Phosphor Icons](https://phosphoricons.com/?size=48)のみ。公式 @phosphor-icons/react を使用し、手描きアイコン・別ライブラリ・絵文字への置換をしない |
| 左揃え | 縦に並ぶ見出し・本文・ラベル・入力・リストの開始位置を同じ左端へ揃える。中央揃えや均等配置で文字の左端をばらつかせない |
| 絵文字 | 操作・見出し・通知・装飾に使用しない。状態は文章とPhosphorアイコンで伝える |
| カード | 各項目をカードにしない。余白・罫線・リスト・段落を基本とし、比較や独立した選択が必要な箇所だけに限定する。カードを入れ子にしない |
| タップ領域 | ボタン・リンク・選択・閉じる操作は最低48×48 CSS px。主要ボタンは高さ52px以上、隣接操作間は8px以上空ける。アイコンの絵の大きさと当たり判定を混同しない |

## 操作と表示

- 本文・入力は16px以上、本文の行間は1.6以上。入力ズーム・文字拡大・画面の向き変更を妨げない。
- 画面の左右余白は20〜24pxを基準に揃える。文章と入力は同じ開始位置に置き、途中の長いコード/名前も折り返す。
- 各画面で次に行う主要操作を1つ明確にする。処理中は短い状態名を表示する。単独制作では他人の操作待ちを作らない。
- 制作開始や完成の前に対象・内容を確認できるようにする。専用の確認画面がある操作はその画面の確定ボタンで完結させ、確認ダイアログを重ねない。別途必要なダイアログはフォーカス移動・閉じる操作・元のボタンへの復帰を備える。
- 入力ラベルは常に表示する。エラーは該当項目と関連付け、入力内容を残して修正/再試行できるようにする。
- 処理中は進行中の操作を明示し、連打を防ぐ。通信結果が不明なら同じrequestIdを使い、制作や完了を意図せず二重に実行しない。
- モック使用時は「体験版」の短い状態ラベルだけを表示する。保存範囲や接続方法の説明は開発文書に記載する。
- 色だけで操作可否・成功・エラーを伝えない。フォーカスを見える状態にし、キーボード操作・画面読み上げにも対応する。
- 操作時の外側のフォーカス枠は表示しない。言語選択・並べ替えのselectには下線も追加しない。キーボード操作の位置はselectでは文字の太さ、その他では文字・コントロール内の下線で示し、削除した枠や線を再追加しない。
- 日英を同じ情報構造で提供する。英語の長文、200%の文字拡大、safe-areaとソフトウェアキーボードで主要操作を隠さない。ヘッダーと進捗は必要に応じて折り返し、下部操作を入力フォーム・工程本文へ重ねない。文字サイズは利用者の設定を尊重する。
- 旧参加URLでは共同制作を再開させず、理由を説明してホームへ戻せるようにする。

320/375/390/430pxで左揃え、横はみ出し、48pxの操作領域、日英、待機・空・入力エラー・通信失敗を確認する。画像追加時は実写/出典を、アイコン追加時はPhosphorを確認する。自動検査だけで実機確認済みとは扱わない。
